# Contributing to Foldworks

Thank you for your interest in Foldworks.

Foldworks is currently in its product-specification and pre-development stage.
Application implementation has intentionally not begun.

## Before contributing

Please read:

1. [Product Constitution](PRODUCT_CONSTITUTION.md)
2. [README](README.md)
3. relevant documentation under [`docs/`](docs/)

The Product Constitution defines principles that contributions must respect.

## Current contribution stage

At this stage, the most useful contributions are likely to involve:

- paper-model domain knowledge;
- real-world collection organization;
- file-format research;
- representative sample cases;
- UX observations;
- identification of edge cases;
- review of specifications and architectural decisions.

Large implementation contributions are premature until the product
specification and initial architecture have been established.

## Future code contributions

Once implementation begins, contribution requirements will include documented
development setup, formatting and linting rules, tests, review expectations,
and security requirements.

These will be added when they become real rather than invented prematurely.

## AI-assisted contributions

AI-assisted contributions are welcome.

They are held to the same standards as any other contribution.

Contributors remain responsible for understanding, reviewing, testing, and
having the right to submit what they contribute.

Do not assume generated code is correct, secure, appropriately licensed, or
compatible with the project merely because an AI system produced it.
