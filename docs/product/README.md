# Product Documentation

This directory contains the canonical product specification for Foldworks.

The [Foldworks Product Constitution](../../PRODUCT_CONSTITUTION.md) establishes
the project's foundational principles. Documents here translate those
principles into increasingly precise product definitions and requirements.

Expected subjects include:

- Model
- Library
- User
- Designer
- Publisher
- Collection
- Category
- Tag
- Asset
- Build
- Variant
- metadata
- filesystem behavior
- import and reconciliation
- search and filtering
- duplicate handling
- export, backup, and restore
- unsupported and corrupt files

Product documentation should describe **what Foldworks must do and why**
without unnecessarily prescribing implementation details.

When a product decision has architectural consequences, those consequences
belong in the architecture documentation or an ADR.
