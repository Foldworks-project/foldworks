# File Formats

This directory contains research and specifications concerning file formats
Foldworks may encounter.

Expected subjects include:

- PDF
- PDO
- raster image sheets
- SVG
- archives
- other paper-model formats discovered during research

Format support should distinguish between recognizing a format, extracting
metadata, generating previews, understanding structure, and editing content.

Deep support for one format must not make other formats second-class Models.
