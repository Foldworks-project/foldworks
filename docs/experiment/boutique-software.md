# The Boutique Software Experiment

Foldworks is both a paper-model application and an experiment in AI-assisted
software development.

The experiment asks whether generative AI can reduce the cost and organizational
requirements of producing high-quality software enough to make excellent
applications viable for communities that conventional software economics often
underserve.

Paper-model collectors are intentionally a niche test case.

The working thesis is not that AI eliminates the need for humans.

It is that AI may dramatically increase what an individual with substantial
domain knowledge can accomplish.

This experiment will eventually document development process, human effort,
AI/tool costs, important prompts and specifications, mistakes, corrections,
successful approaches, failed approaches, and lessons learned.
