# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for significant
Foldworks project and technical decisions.

ADRs preserve:

- the context in which a decision was made;
- the decision itself;
- its rationale;
- important consequences.

Accepted decisions should not be silently rewritten when circumstances change.
A later ADR should supersede an earlier decision when appropriate.
